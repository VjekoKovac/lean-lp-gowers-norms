# Reused geometric Brascamp–Lieb formalization

The sharp Euclidean upper bound uses Yi Han's proof of the geometric Brascamp–Lieb inequality on finite-dimensional real inner product spaces. The source is the Apache-2.0 repository `hanyi162013-Yihan/geometric-brascamp-lieb`, commit `9155169a5ba8f7db77c01c446430e50c0daceb7d`. [Upstream source at the pinned commit](https://github.com/hanyi162013-Yihan/geometric-brascamp-lieb/tree/9155169a5ba8f7db77c01c446430e50c0daceb7d) · [License included with the source](../GeometricBrascampLieb/LICENSE)

The local `GeometricBrascampLieb` directory contains the imported upstream proof modules. The upstream repository targets Lean and Mathlib 4.33.0. The port builds with this repository's Lean 4.36.0 and pinned Mathlib. The changes introduce explicit module headers, public imports, and exported declarations. They adapt measurable null-set pullbacks, the Gaussian-convolution integrability proof, product monotonicity, and convergence-in-measure API calls to the pinned versions. They also update a small number of renamed Mathlib lemmas. The mathematical theorem in `GeometricBrascampLieb.Datum.lintegral_prod_le` is the upstream theorem.

The application to sharp Young is new to this project. It constructs the coisometric three-map frame, computes the measure factors in the linear changes of variables, and applies nonlinear duality. The Euclidean recurrence then gives the constant in the paper. The upper bound, its minimality, and the full Gaussian equality characterization have kernel-checked proofs. The equality argument uses the upstream heat-flow construction. The positive-tolerance argument also uses the upstream heat flow. Local compactness of the project’s nonlinear Euler map and a continuity argument give the diagonal Young stability needed in Theorem 1.3(b). Section 4 of the source paper invokes Christ’s theorem at this step. [Detailed proof and attribution](EUCLIDEAN-REVIEW.md)

The statement-and-kernel layout follows the Durcik–Fraccaroli–Roos example and the Palomar template. These repositories supply the project examples and verification workflow, respectively.
